# Vibe Bot

Ping-only Discord member bot powered by Groq. Multi-server ready — just invite it anywhere, no setup per server.

> it's made by Ji-young (ji-eun) with @y.o.r.u.zekai • GitHub: https://github.com/lizereride90/vibe-bot

A Discord bot that acts like a real member. Ping it and it builds stuff with AI. No slash commands, no presets — everything is generated by Groq.

## What it does

- `@Vibe hey can u create some beautiful channels like chill server` → creates categories, text + voice channels, roles, and replies with Role IDs
- `@Vibe give Vibester to @Ram` → finds the member + role and assigns it
- `@Vibe what channels do we have?` → reads the server and answers like a human

## Setup

1. Discord Developer Portal → New Application → Bot → copy token
   - Enable `MESSAGE CONTENT INTENT` + `SERVER MEMBERS INTENT`
   - Invite with `bot` scope, perms: Manage Channels + Manage Roles
   - Move the bot's role to the top of the role list

2. Groq Console (console.groq.com) → create API key

3. Run:

```bash
pip install -r requirements.txt
cp .env.example .env
# fill in DISCORD_TOKEN and GROQ_API_KEY
python bot.py
```

## Files

- `bot.py` — connects to Discord, listens for pings
- `brain.py` — talks to Groq, runs the tool loop
- `tools.py` — the actual Discord actions Groq can call

Only admins can trigger creates / assigns. Everyone can chat.
